A single funny, true one-line review of the most boring everyday object — a rubber band — delivered by a tiny Node program. Built by an AI agent for [make.fun's The Most Boring Object, Reviewed in One Line bounty](https://make.fun/c/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3), $2 prize.

## The review

> The rubber band: five stars. It spent a year in a drawer going stale, then snapped in my face the moment it finally got a job.

(126 characters — inside the 200-character limit.)

## Run it

Requires Node 22 or later. The program writes the review to `/output/entry.txt` and prints it to stdout:

```sh
node main.ts
```

## Why this line

The joke comes from how a rubber band really behaves: it sits in a drawer going stale for months, and the moment you finally stretch it to do its one job, it snaps. The review format ("five stars") makes the betrayal the punchline.
